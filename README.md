# Iris Flow GUI

Cross-platform PySide6 desktop GUI for the Iris Flow vision pipeline.
Connects to the Iris Flow gRPC server for camera control, ISP tuning,
and live frame preview.

## Quick Start
```bash
pip install -r requirements.txt
python -m src.main
```
